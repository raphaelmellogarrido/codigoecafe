# Faz Tudo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the "Faz Tudo" portfolio project (handyman services site) at `/faz-tudo`, with a service-selector budget-request flow, an interactive before/after gallery, a service-area map, testimonials, and a floating urgent-WhatsApp button — then link it from the main site's portfolio grid.

**Architecture:** Client-only React (Vite), 3 routes under a shared layout (`FazTudo.jsx` renders navbar + `<Outlet/>` + footer + floating WhatsApp button). No new dependencies — Leaflet (already used by `PropertyMap.jsx`/`DeliveryMap.jsx`) for the map, hand-rolled pointer events + `clip-path` for the before/after slider, `useState` for the service-selector, and `wa.me` links for all "contact" actions. All content (services, gallery, testimonials) is static data in plain `.js` files.

**Tech Stack:** React 18, React Router 7, Leaflet 1.9 (already a dependency), `react-icons` (already a dependency). No test framework exists anywhere in this repo (verified: no `*.test.*`/`*.spec.*` files, no jest/vitest in `package.json`) — verification is manual, via the dev server, matching how every other project in `src/pages/projects/` was built.

## Global Constraints

- No new npm dependencies — reuse Leaflet, `react-icons`, `react-router-dom` only (from spec: "Sem dependências novas").
- WhatsApp number: `351913247176` (same number already used in `Pizzaria/whatsapp.js`).
- Quote message format (exact, from spec): `Olá, eu preciso dos seus serviços de: <a>, <b> e <c>` — lowercase service names, Oxford-style "e" before the last item, no price/value anywhere in the message or on screen.
- Urgent-button message (exact, from spec): `Olá, preciso de atendimento urgente.`
- Service-area map center: Méier, Rio de Janeiro, `lat: -22.9019, lng: -43.2778`, radius 40km — fixed, no geolocation.
- Route `/faz-tudo` lives outside the `/projetos` prefix, lazy-loaded in `App.jsx`, matching `/pizzaria` and `/imobiliaria`.
- CSS class prefix: `ft-` (matches `pz-` in Pizzaria, `im-` in Imobiliária), one file `FazTudo.css`.
- Dark premium palette: background `#14100d`/`#1c1611`, text `#f3ede6`, accent orange `#ff7a1a` (hover `#e8630a`).
- Only allowed change to the main site: one new object appended to the `projects` array in `src/pages/Home.jsx` — no other file outside `src/pages/projects/FazTudo/` is touched except `App.jsx` (routes) and `Home.jsx` (one array entry).

- [ ] **Step 5: Write `whatsapp.js`**

```js
// src/pages/projects/FazTudo/whatsapp.js
// Monta as mensagens (pedido de orçamento e atendimento urgente) e o link
// wa.me para abrir o WhatsApp já preenchido.

import { WHATSAPP_NUMBER } from './constants';

function formatServiceList(names) {
  if (names.length === 0) return '';
  if (names.length === 1) return names[0];
  return `${names.slice(0, -1).join(', ')} e ${names[names.length - 1]}`;
}

export function buildQuoteMessage(serviceNames) {
  return `Olá, eu preciso dos seus serviços de: ${formatServiceList(serviceNames)}`;
}

export function buildUrgentMessage() {
  return 'Olá, preciso de atendimento urgente.';
}

export function buildWhatsappUrl(message, phoneNumber = WHATSAPP_NUMBER) {
  return `https://wa.me/${phoneNumber}?text=${encodeURIComponent(message)}`;
}
```

```jsx
// Calculadora de orçamento: seleção de serviços (sem preço, só a lista) que
// monta a mensagem e abre o WhatsApp. Estado local (Set de ids) — sem
// persistência, sem backend.

import { useState } from 'react';
import { SERVICES } from './servicesData';
import { buildQuoteMessage, buildWhatsappUrl } from './whatsapp';

export default function FazTudoOrcamento() {
  const [selectedIds, setSelectedIds] = useState(() => new Set());

  function toggleService(id) {
    setSelectedIds((prev) => {
      const next = new Set(prev);
      if (next.has(id)) {
        next.delete(id);
      } else {
        next.add(id);
      }
      return next;
    });
  }

  const selectedNames = SERVICES.filter((service) => selectedIds.has(service.id)).map((service) =>
    service.name.toLowerCase()
  );
  const hasSelection = selectedNames.length > 0;
  const whatsappHref = hasSelection ? buildWhatsappUrl(buildQuoteMessage(selectedNames)) : undefined;

  return (
    <section className="ft-orcamento section">
      <div className="container">
        <h1 className="ft-orcamento-title">Monte o seu orçamento</h1>
        <p className="ft-orcamento-subtitle">
          Selecione os serviços que precisa e receba um orçamento rápido pelo WhatsApp.
        </p>

        <div className="ft-services-grid" role="group" aria-label="Serviços disponíveis">
          {SERVICES.map((service) => {
            const isSelected = selectedIds.has(service.id);
            return (
              <button
                key={service.id}
                type="button"
                className={`ft-service-card${isSelected ? ' ft-service-card-selected' : ''}`}
                aria-pressed={isSelected}
                onClick={() => toggleService(service.id)}
              >
                {service.name}
              </button>
            );
          })}
        </div>

        <a
          href={whatsappHref}

          rel="noopener noreferrer"

          aria-disabled={!hasSelection}
          onClick={(event) => {

          }}
        >
          Pedir orçamento no WhatsApp{hasSelection ? ` (${selectedNames.length})` : ''}
        </a>
      </div>
    </section>
  );
}
```

```jsx
// src/pages/projects/FazTudo/BeforeAfterSlider.jsx
// Slider de comparação antes/depois: a imagem "depois" fica por cima,
// recortada com clip-path até a posição X do handle. Arrastar o handle
// (pointer events) ou usar as setas do teclado (handle é focável, role=slider)
// move o recorte. Sem dependências externas.

import { useCallback, useRef, useState } from 'react';

export default function BeforeAfterSlider({ beforeImage, afterImage, beforeLabel = 'Antes', afterLabel = 'Depois' }) {
  const containerRef = useRef(null);
  const [position, setPosition] = useState(50); // % da largura, a partir da esquerda

  const updateFromClientX = useCallback((clientX) => {
    const el = containerRef.current;
    if (!el) return;
    const rect = el.getBoundingClientRect();
    const ratio = (clientX - rect.left) / rect.width;
    const clamped = Math.min(1, Math.max(0, ratio));
    setPosition(clamped * 100);
  }, []);

  function handlePointerDown(event) {
    event.currentTarget.setPointerCapture(event.pointerId);
    updateFromClientX(event.clientX);
  }

  function handlePointerMove(event) {
    if (event.buttons !== 1) return;
    updateFromClientX(event.clientX);
  }

  function handleKeyDown(event) {
    if (event.key === 'ArrowLeft') setPosition((prev) => Math.max(0, prev - 5));
    if (event.key === 'ArrowRight') setPosition((prev) => Math.min(100, prev + 5));
  }

  return (
    <div ref={containerRef} className="ft-ba-slider">
      <img src={beforeImage} alt={beforeLabel} className="ft-ba-image ft-ba-image-before" draggable={false} />
      <div className="ft-ba-image-after-wrap" style={{ clipPath: `inset(0 ${100 - position}% 0 0)` }}>
        <img src={afterImage} alt={afterLabel} className="ft-ba-image ft-ba-image-after" draggable={false} />
      </div>
      <div
        className="ft-ba-handle"
        style={{ left: `${position}%` }}
        role="slider"
        tabIndex={0}
        aria-label="Arraste para comparar antes e depois"
        aria-valuenow={Math.round(position)}
        aria-valuemin={0}
        aria-valuemax={100}
        onPointerDown={handlePointerDown}
        onPointerMove={handlePointerMove}
        onKeyDown={handleKeyDown}
      >
        <span className="ft-ba-handle-arrows">↔</span>
      </div>
      <span className="ft-ba-badge ft-ba-badge-before">{beforeLabel}</span>
      <span className="ft-ba-badge ft-ba-badge-after">{afterLabel}</span>
    </div>
  );
}
```

```jsx
// src/pages/projects/FazTudo/ServiceAreaMap.jsx
// Mapa "cru" com Leaflet, no mesmo espírito do PropertyMap.jsx da Imobiliária:
// tile OpenStreetMap (sem chave de API), scroll-zoom desligado. Diferença: em
// vez de um marcador de imóvel, mostra um círculo representando o raio de
// atendimento a partir de um centro fixo.

import { useEffect, useRef } from 'react';
import L from 'leaflet';
import 'leaflet/dist/leaflet.css';

function centerIcon() {
  return L.divIcon({ className: 'ft-map-pin', iconSize: [22, 22] });
}

export default function ServiceAreaMap({ center, radiusKm, label }) {
  const mountRef = useRef(null);

  useEffect(() => {
    if (!mountRef.current) return undefined;

    const map = L.map(mountRef.current, {
      zoomControl: true,
      attributionControl: false,
      scrollWheelZoom: false,
    }).setView([center.lat, center.lng], 9);

    L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', { maxZoom: 18 }).addTo(map);

    const marker = L.marker([center.lat, center.lng], { icon: centerIcon() }).addTo(map);
    if (label) marker.bindPopup(label);

    const circle = L.circle([center.lat, center.lng], {
      radius: radiusKm * 1000,
      color: '#ff7a1a',
      weight: 2,
      fillColor: '#ff7a1a',
      fillOpacity: 0.15,
    }).addTo(map);

    map.fitBounds(circle.getBounds());

    return () => {
      map.remove();
    };
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [center.lat, center.lng, radiusKm, label]);

  return <div ref={mountRef} className="ft-map" />;
```
